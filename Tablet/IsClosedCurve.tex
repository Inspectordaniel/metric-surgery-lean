\begin{definition}[Closed curve]
  Let $E$ be a metric space and $\gamma \in \Theta(E)$ (\noderef{Curve}). We say $\gamma$ is a
  \emph{closed curve}, written $\mathrm{IsClosedCurve}(\gamma)$, when
  $\gamma(\length(\gamma)) = \gamma(0)$. This is exactly the paper's definition of $\Theta_c(E)$,
  the set of closed curves (paper.tex line 556): $\gamma \in \Theta_c(E)$ iff
  $\gamma(\length(\gamma))=\gamma(0)$.
\end{definition}
